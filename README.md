# Enicomp Landings

Monorepo de landing pages estáticas geradas a partir do [Enicomp](https://github.com/igornichele/enicomp).

Cada pasta em `sites/<slug>/` é uma landing page. URL no formato:

```
https://enicomp-landings.vercel.app/sites/<slug>/
```

Deploy automático via Vercel a cada `git push`.
